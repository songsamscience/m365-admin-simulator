# Microsoft 365 관리 센터 실습 사이트 (연수용)

학교 디벗 담당 선생님 연수에서 Microsoft 365 관리 센터의 계정 관리 업무를 연습하는 **연수용 실습 사이트**입니다.
실제 Microsoft 365 관리 센터와 연결되지 않으며, 학교 이름·도메인·사용자·숫자는 모두 가상입니다. 화면과 문구는 실제와 다를 수 있습니다.

- 사이트: https://songsamscience.github.io/m365-admin-simulator/
- 실습 방법 안내 PDF(미션별 실제 화면 캡처): https://songsamscience.github.io/m365-admin-simulator/guide.pdf

## 출처
- **원본 소스**: 온라인학교 강현욱 선생님 — https://seoulonline.github.io/msadmin/
- **수정·편집**: 송세호 선생님 — 2026년 최신 관리 센터 디자인(새 대시보드·검정 머리 막대·메뉴 순서), 실습 미션·따라하기, 안내 PDF 추가

## 실습 미션 (연수 자료 「0. 계정 세팅 실습해 보기」 순서)
| 번호 | 미션 |
|---|---|
| 1 | 개인 학생 계정 생성하기 |
| 2-1 | 학생 단체 계정 생성하기 ① 표에 직접 입력 |
| 2-2 | 학생 단체 계정 생성하기 ② CSV 파일로 대량 업로드 |
| 3 | 개인 비밀번호 초기화하기 |
| 4 | 단체 비밀번호 초기화하기 |
| 5 | 저장 용량 변경하기 (1024GB) |
| 6 | 표시 이름 변경하기 |
| 7 | MFA(다단계 인증) 사용 해제하기 |
| 8 | 그룹(팀) 설정해 보기 |

앞 미션을 끝내야 다음 미션이 열립니다. 「따라하기」는 노란 테두리와 안내 띠로 단계마다 안내하고, 「혼자 해보기」는 결과로 완료를 판정합니다.

## 파일
- `index.html` — 관리 센터(한 파일, CSS·JS 포함)
- `mfa.html` — Microsoft Entra 관리 센터 › 사용자 단위 다단계 인증 (새 탭)
- `sharepoint.html` — SharePoint 관리 센터 › 설정 › 저장 한도 (새 탭)
- `manual.html` — 기능 설명서
- `guide.pdf` — 실습 방법 안내(57쪽)

연수용 비공식 교육 자료이며 Microsoft와 무관합니다.
